# Security policy

## Reporting

Please use GitHub's **private vulnerability reporting** (the repository's
Security tab) for anything sensitive. Less sensitive issues can go in a normal
GitHub issue.

There is no bug bounty. Coordinated disclosure within 30 days is appreciated,
and we will acknowledge a report as soon as we have read it.

## Supported versions

`main` is the only supported branch. Production runs from it, on Railway in a
European region.

## Scope

In scope: the deployed application at its production domain, and the code in
this repository — the HTTP server, the oRPC API, authentication, media
handling and the moderation system.

Out of scope: findings that require a compromised developer machine, reports
generated by a scanner with no demonstrated impact, and the third-party
services this app depends on (report those to their own vendors).

The attack-surface notes an external reviewer should read first — public
endpoints, the one anonymous RPC and how it is capability-gated, session and
media gating, upload validation, rate limiting, and environment isolation —
are maintained in **[docs/security.md](docs/security.md)**.
